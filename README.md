## 四、答题方法

### 1. 八股题的三段式

```
是什么（一句话定义）
→ 为什么这么设计（解决什么问题、代价是什么）
→ 我在项目里怎么用（结合真实细节，没有就说没有）
```

例：问「为什么用 Redis Stream」
> 「Stream 是 Redis 的追加日志结构，有消费组和 ACK（定义）；我用它是为了长任务异步化又不引入 MQ（为什么）；项目里用它跑了简历分析、向量化、评估三条管道，重试 3 次后置失败（怎么用）。」

### 2. 不要背「结论」，要背「取舍」

面试官区分「背过」和「做过」的方式，就是问「那如果换成 X 呢」。
- ❌「我们用了 Redis 做缓存」→ 追问「一致性怎么保证」就崩。
- ✅「我们用 Redis 缓存热点，接受秒级不一致，靠 TTL 和 binlog 删除兜底」。

### 3. 不会的题怎么答

> 「这块我没有实际做过，我的理解是……（说出你知道的部分），不确定的地方我不猜。如果按这个思路，我会先验证 X。」

**比编造安全十倍。** 面试官不指望你什么都会，但会记住你「不懂装懂」。

## 六、维护建议
